# Reframe

Goal: a different question, not a better answer to the same question.

## 1. Name the current frame

The user may describe the problem by thinking out loud, often dictated: long, circling, contradicting itself. The circling is the clue. Where they keep returning is usually the frame they are stuck in.

Write down, briefly:

- **The problem** as the user states it, in their words.
- **The frame**: who the actor is, what counts as success, what the unit is, what is treated as fixed.
- **3-5 hidden assumptions** everyone takes for granted. Phrase each as a sentence that could be false ("Colleagues need to open the tool themselves").

Show this to the user. Naming the frame is often half the win.

## 2. Pick 2-3 techniques

| Situation | Technique |
|---|---|
| "How do we get X?" (default) | Provocation |
| The problem feels unique and nobody knows where to look | Metaphor transfer |
| A product, team or process facing competition or change | What-if attack |

### Provocation

Make a deliberately unreasonable statement and mark it **Po:** so nobody argues with it. Types:

- **Reversal**: the thing goes the other way. Normal: customers pay us. Po: we pay customers.
- **Exaggeration**: multiply or divide a number by 100. "Po: the meeting lasts one minute."
- **Escape**: drop one assumption from step 1. "Po: there is no form."
- **Distortion**: change an order or a relationship. "Po: the report is written before the work."
- **Wishful thinking**: "Po: it would be great if..." something impossible.

When provocations stall, use **random entry**, a separate technique. The word must not be chosen to fit. Ask the user to name an object they can see right now, or count the letters of the problem statement's first word and take that position from this list (wrap around): bridge, soup, elevator, tattoo, queue, seed, mirror, dog, receipt, lighthouse. Then force connections between the word and the problem.

Then **move** from the provocation to an idea without judging it. Ask:

- What principle does it rely on?
- What is different from what we do now?
- What would happen moment by moment if it were real?
- Under what circumstances would it make sense?
- What is the useful part?

End each provocation with a usable idea. Provocations are tools, not proposals. Don't defend them.

### Metaphor transfer

1. Strip the problem to its structure, e.g. "many requests, few slow handlers, some urgent".
2. Pick 2-3 distant fields with the same structure: emergency-room triage, air-traffic control, a restaurant kitchen, an ant colony, the immune system, a football team, a theatre.
3. For each, name the mechanism that solves it. The triage nurse is a cheap first pass that sorts patients before the expensive doctor.
4. Translate the mechanism back into concrete moves.
5. Test: does it produce a step the literal frame missed? If it only produces a mood ("be like a jazz band"), drop it.

### What-if attack

Treat the user's product, process or team as the incumbent. Generate what-ifs in four lanes:

- **Technology**: what if the expensive part became free or instant?
- **Business model**: what if someone charged per outcome, gave it away, or changed who pays?
- **Customer experience**: what if the customer never had to do step X?
- **Market**: what if the target customer were the one we ignore?

For each what-if that survives: who would do this, why the incumbent can't easily copy it, and whether to defend, copy or ignore.

## 3. Output

```
**Current frame:** ...
**Assumptions we've been making:**
1. ...
2. ...

**New frames**
1. **<short name>** (Po: ... / metaphor: ... / what-if: ...)
   Breaks assumption: #2
   New question: "How might we ...?"
   Next step: ...
```

Give 3-5 frames. Close with one line: which assumption looks most worth testing first, and why.

## Rules

- Never return frames without next steps.
- Don't slide into a long idea list. If the user wants volume on one frame, switch to brainstorm on it.
- If the user's frame survives every attack, say so. That is a result too.

---

Provocation and movement come from Edward de Bono, *Lateral Thinking* (1970) and *Serious Creativity* (1992).
